軽量スクラッチ検出モデル

モデル容量
元モデル: 1,157,553 bytes (1.158 MB)
前回の大型モデル: 49,885,085 bytes (49.885 MB)
今回の軽量モデル: 1,174,373 bytes (1.174 MB)
大型モデルから 97.65% 削減。
FP32形式のまま。容量削減は構造変更によるもので、精度を落とす量子化はしていません。

構造
元ONNX内の学習済み畳み込み20層を移植し、重みを固定。
移植部分は元モデルの確率出力との数値一致を確認済み。
元モデルは入力RGBのRチャンネルを使っていました。この動作も保持。
元解像度のRGB、局所コントラスト、元モデル由来の確率を入力する小さな輪郭補正層を追加。
全体 288,262 パラメーター。追加学習する部分は 2,741 パラメーター。
元の約256×505に縮小する検出経路に、縮小しない補正経路を組み合わせています。
元モデルで強く見落とす傷まで必ず回復できるわけではありません。

使い方
D:\InnCoreTech\Scratch_Detection の run_video.bat または run_video_lite.bat をダブルクリック。
入力は同じフォルダーの video_one_ai.mp4。GPUがあればGPUで処理します。
結果は scratch_lite_result.mp4 と scratch_lite_result.jsonl に保存。
別の動画をバッチへドラッグ＆ドロップすることも可能です。
元のモデル one_ai_model.onnx は変更していません。前回大型版は run_video_large.bat から起動できます。
動画出力は音声を引き継ぎません。

コマンドでの実行（元フォルダーへ移動してから）
call "C:\Users\PrimaLab\anaconda3\Scripts\activate.bat" CarDamage
python detect_scratches_lite.py --model scratch_lite.pt --device auto --input video_one_ai.mp4 --output scratch_lite_result.mp4
ONNX/CPU版:
python detect_scratches_lite.py --model scratch_lite.onnx --input video_one_ai.mp4 --output scratch_lite_result_cpu.mp4
静止画は --input 入力.png --output 結果.png で処理可能。
既定の閾値は 0.8。検証画像のDice最大で選択。
--threshold を下げると感度を上げられますが、誤検出が増える可能性があります。
--min-pixels 3 が既定。1画素幅の線も残し、モルフォロジー開処理は行いません。

評価結果（以前から使用している開発評価33枚）
全体Dice: 元モデル 71.45% → 軽量モデル 79.38%
全体IoU: 元モデル 55.59% → 軽量モデル 65.80%
全体Precision: 元モデル 70.52% → 軽量モデル 76.69%
全体Recall: 元モデル 72.41% → 軽量モデル 82.25%
小さな傷の注釈画素Recall: 元モデル 70.68% → 軽量モデル 79.65%
細い傷の注釈画素Recall: 元モデル 60.28% → 軽量モデル 67.72%
誤検出画素: 元 4,264 → 軽量 3,521
小さな傷は面積1024画素以下、細い傷は2×面積÷外周長が6画素以下。
対象件数は傷17個、小さな傷12個、細い傷3個（カテゴリ重複あり）。
上記の細傷・小傷指標は傷の画素のうち何%を拾えたかです。傷の個数単位の検出率ではありません。
個数単位指標（注釈領域25%以上を捉えたら検出）は lite_evaluation.json を参照。
採用エポック: 22。チェックポイントと閾値は検証33枚のみで選択。
補正層の学習143枚・検証33枚・開発評価33枚・境界除外24枚。
元モデルの学習履歴は不明で、この評価画像を既に学習している可能性があります。
元の重みを継承しているため、軽量版についても未知画像への汎化性能の証明にはなりません。
また、この33枚は前回開発時に確認済みです。新しい撮影条件での独立評価が必要です。

動作確認
ONNX checker成功。入力サイズ96×144、384×640、640×1264、808×1288でPyTorchとONNXの一致を検証。
GPUとONNXの最大絶対差: 0.000175
CPU推論平均: 0.0651 秒/画像（評価33枚、前後処理除外）。
GPU参考: 0.0109 秒/画像（1画像での参考計測、前後処理込み）。
ファイルサイズが近くても、元解像度補正を追加しているため元モデルと同じ速度とは限りません。

入力・出力
入力名 rgb、float32、[1,3,H,W]、RGB、0～1。
出力名 scratch_probability、float32、[1,1,H,W]、0～1の確率。
画像を丸ごと入力してください。このモデルはタイル分割を前提としていません。
旧 visualize_scratches.py はクラスID出力を想定しているため、そのまま使うことはできません。

再学習（既存CarDamage環境で使用）
python train_scratch_lite.py --epochs 40 --steps 60
python evaluate_scratch_lite.py
PyTorch、NumPy、OpenCV、ONNX、ONNX Runtime等が必要。
追加の学習済みモデルのダウンロードは不要。元フォルダーの one_ai_model.onnx から初期化します。
再実行は軽量モデル・評価結果を上書きするので、保持したい結果はコピーしてください。
設定: seed83、AdamW、学習率0.001→0.00005、BCE+Dice、元モデルの重み固定。
